# TrustTrack AI

Smart Real-Time Monitoring & Inspection platform for government project monitoring.

## MVP
- Project Command Dashboard
- Verified Field Evidence Capture
- AI Exception Detection + Explainable Alerts
- Officer action workflow

## Product loop
**SEE → CAPTURE → VERIFY → DETECT → EXPLAIN → ACT**

## Run locally
```bash
npm install
npm run dev
```

## Demo strategy
The first demo milestone uses prepared project data so the critical monitoring workflow remains reliable. Supabase, Python AI, maps, CCTV/RTSP and WebRTC can be integrated after the dashboard and evidence workflow are stable.
